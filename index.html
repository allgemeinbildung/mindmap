Mindmap kopiert!

Der SVG-Code der Mindmap wurde in Ihre Zwischenablage kopiert.

So fügen Sie die Mindmap in eine Software ein:

  1. Öffnen Sie Excalidraw (oder eine andere SVG-kompatible Software wie Obsidian, Inkscape, Figma).
  2. Fügen Sie den Inhalt mit Strg+V (Windows) oder Cmd+V (Mac) ein.
  3. In Excalidraw: Klicken Sie oben links auf das Hamburger-Menü (3 Striche), wählen Sie "Exportieren als Bild..." und wählen Sie Ihr gewünschtes Format (z.B. PNG, SVG).
